# VBAN Deck 0.2.2 - Steam Deck / Linux

This patch fixes receiver settings in the Decky Loader plugin and removes the preset destination IP.

## Fixed

- **IP address stays entered in Game Mode.** Background status updates no longer overwrite the destination IP, port, stream name, or advanced target while you edit them.
- **Fixed the Python exception when starting a stream.** The Decky backend now initializes settings using the correct Decky settings directory.
- **Clearer start errors.** Invalid settings and settings-save failures now display their actual error message.
- **No preset receiver IP.** Fresh installs start with a blank destination address. Enter your receiver PC's IP before starting. Existing saved settings are preserved.

## Downloads

- **Steam Deck Game Mode / Decky Loader:** `VBANDeck-0.2.2.zip`
- **Steam Deck Desktop Mode / Linux:** `VBANDeck-0.2.2.flatpak`

Install the ZIP through Decky Loader's plugin installer, or install the Flatpak through your desktop's software installer. Set your receiver address and use the same UDP port and stream name in VBAN Deck and your VBAN receiver.

The Decky fixes were tested on Steam Deck before release. Audio remains 48 kHz stereo, signed 16-bit PCM over VBAN.
